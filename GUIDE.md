# How to Request Micro Tasks

Welcome to our micro task execution service! If you have a small programming task that needs completion, such as data entry or simple web scraping, feel free to request it here. To get started:

1. Fork this repository and create your own copy.
2. Open an issue in your forked repository with a clear description of the task you need done.
3. Indicate the payment terms ($1/hour is our starting rate).
4. We will review your request and start working on it as soon as possible.
